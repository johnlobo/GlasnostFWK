# nave

El juego terminado de la guía [Tu primer juego](../../docs/first-game.md): una nave que se
mueve con el cursor, tres drones que patrullan, sprites convertidos desde un PNG, animación
de dos fotogramas, colisión con contador de golpes y texto.

Es la copia acumulada de `docs/first-game/step1`, `step2` y `step3`; un test
(`tests/test_first_game_guide.py`) comprueba que coincide. Para trabajar sobre él como
proyecto propio, sigue la guía desde `glasnost new`.

```sh
make            # desde esta carpeta: compila nave.bin, nave.cdt y nave.dsk en .build/nave/
```

En un CPC: `RUN"NAVE`.
